# sphinxcontrib-mermaid

Embed [Mermaid](https://mermaid.js.org/) diagrams in Sphinx documents. HTML
output renders in the browser with a bundled copy of Mermaid, sized to stay
readable, with pan, zoom, and a fullscreen view. LaTeX, texinfo, and static
image output use [mermaid-cli](https://github.com/mermaid-js/mermaid-cli).
